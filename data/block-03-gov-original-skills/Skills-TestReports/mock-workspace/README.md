# Mock Workspace — 政务办公 SKILLs 测试工作区

本目录模拟一个真实政务机关的工作区文件结构，供 OpenClaw 加载 SKILLs 测试使用。

## 目录结构

```
mock-workspace/
  incoming/          ← 外来收文（待登记处理）
    ├── 来函-XX市科技局-申请2026年度科技专项经费.md       约 1,200 字
    ├── 通知-省工信厅-防汛安全隐患排查紧急通知.md           约 1,000 字
    ├── 请示-业务科-申请增加办公设备采购预算.md             约 1,500 字
    └── 报告-督查科-上半年重点工作进展.md                   约 1,400 字
  drafts/            ← 草稿区（空，供 AI 写入起草结果）
  registers/         ← 台账登记区
    incoming/
      └── 收文台账.md                                      约 500 字，含 2 条记录
    archive/
      └── 归档台账.md                                      约 800 字，含 4 条记录
  emails/inbox/      ← 收件箱（10 封邮件）
    ├── 001-市科技局-科技经费申请函.eml                     约 600 字
    ├── 002-省工信厅-防汛安全检查紧急通知.eml               约 600 字
    ├── 003-区县办事处-询问科技扶持政策细则.eml             约 500 字
    ├── 004-广告商-合作推广方案.eml                         约 400 字（垃圾邮件）
    ├── 005-财务科-催办报销审批.eml                         约 350 字
    ├── 006-人事科-张三请假申请批复.eml                     约 350 字
    ├── 007-上级机关-专项督查交办通知.eml                   约 550 字
    ├── 008-同级单位-联合检查协商函.eml                     约 500 字
    ├── 009-供应商-报价单及产品介绍.eml                     约 350 字（商业推广）
    └── 010-下属单位-申请政策解读培训.eml                   约 500 字
  meeting-records/   ← 会议记录
    └── 2026年第8次办公会议-原始记录.md                      约 2,000 字
```

## 文件类型覆盖

| 类型 | 数量 | 说明 |
|---|---|---|
| 来函 | 1 份 | 同级机关协商函，含经费申请 |
| 请示 | 1 份 | 内部科室上行请示，含预算明细 |
| 通知 | 1 份 | 上级紧急通知，含排查部署 |
| 报告 | 1 份 | 内部科室上行工作报告 |
| 邮件 | 10 封 | 覆盖 P1 紧急/P2 一般/P3 参考/SPAM 垃圾 |
| 会议记录 | 1 份 | 多议题办公会议原始记录 |
| 收文台账 | 1 份 | 2 条已登记收文记录 |
| 归档台账 | 1 份 | 4 条已归档记录（公开/内部/秘密） |

## 测试用法

1. 将此 `mock-workspace` 文件夹复制到 OpenClaw 可访问的路径
2. 在提示词中用实际文件路径引用，例如：
   - "请读取 `mock-workspace/incoming/来函-XX市科技局-申请2026年度科技专项经费.md` 并登记"
   - "请分析 `mock-workspace/emails/inbox/` 下的所有邮件"
   - "请根据 `mock-workspace/meeting-records/2026年第8次办公会议-原始记录.md` 整理会议纪要"
3. OpenClaw 的读写结果体现 SKILLs 的功能差异

## 模拟数据说明

所有文件中的机关名称、人员姓名、电话号码、邮箱地址、文件编号、
金额数据均为虚构模拟数据，如有雷同纯属巧合。
