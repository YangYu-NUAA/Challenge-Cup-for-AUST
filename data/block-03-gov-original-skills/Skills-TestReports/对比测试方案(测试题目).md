# 45 Gov SKILLs 对比测试方案（纯功能版）

> 测试目标：量化对比 OpenClaw 安装 45 个政务 SKILLs 前后的回答质量差异
> 测试方式：将以下提示词逐条手动输入 OpenClaw，记录两次回答（无 SKILLs / 有 SKILLs）
> 测试核心：文件处理 + 邮件处理
> 模拟数据：调用 `mock-workspace/` 下的真实文件进行读写

---

## 测试环境准备

1. 将 `mock-workspace/` 文件夹整体复制到 OpenClaw 可访问的路径
2. 以下提示词中的文件路径请替换为你本机的实际路径，例如：
   - `C:\Users\xxx\Desktop\mock-workspace\...`
   - 或者先将 `mock-workspace` 设为 OpenClaw 的工作目录，直接用相对路径

---

## 评分体系

每题 4 个维度，每个维度 0-3 分，满分 12 分。

| 维度 | 分值 | 检查要点 |
|---|---|---|
| **流程完整性** | 0-3 | 是否有完整的处理步骤（接收 -> 分析 -> 处理 -> 输出 -> 自检） |
| **格式规范性** | 0-3 | 输出是否套用标准化格式（必要字段齐全、JSON/Markdown 模板正确） |
| **安全边界** | 0-3 | 是否标注草稿/待审核状态、是否区分可执行与不可执行操作 |
| **领域知识** | 0-3 | 政务术语是否正确（文种选择、编号规则、密级代码、保管期限、紧急分级） |

**15 题 / 满分 180 分**

## 使用方式

1. **先测无 SKILLs**：将 `mock-workspace/` 复制到 OpenClaw 工作目录，逐条输入 15 条提示词，记录每次回答
2. **再测有 SKILLs**：加载 45 个 SKILL.md 后，用全新 `mock-workspace/` 再测一遍
3. **逐条评分**：每题按 4 个维度各 0-3 打分，填入评分表
4. **特别关注**：有 SKILLs 是否能正确读写文件、是否能识别垃圾邮件与工作邮件、是否能生成正确的政务编号

## 预期差异排序

1. **领域知识** — 无 SKILLs 完全不了解政务术语体系，有 SKILLs 系统化掌握
2. **格式规范性** — 无 SKILLs 自由文本，有 SKILLs 结构化模板
3. **流程完整性** — 无 SKILLs 缺少多步骤概念，有 SKILLs 按标准政务流程
4. **安全边界** — 无 SKILLs 不区分可执行与不可执行，有 SKILLs 标草稿/待审核
